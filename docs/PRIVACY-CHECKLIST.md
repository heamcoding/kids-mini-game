# 개인정보·어린이 서비스 점검 문서

> **이 문서는 법률 자문이 아닙니다.** 코드를 읽고 "지금 무엇을 수집하고 어디로 보내는지"를 정리하고,
> 출시 전에 전문가나 공식 문서로 확인할 질문을 모은 점검표입니다. 법 조항과 스토어 정책은 자주 바뀌므로
> 아래 "확인할 곳"의 최신 원문을 직접 확인하세요. (작성 기준: 2026-11-14, 코드는 `chore/pre-launch` 시점)

이 서비스는 만 3~5세 아이가 노는 앱이지만 **사용자는 보호자(설정 화면)와 아이 모두**입니다. 어린이 대상
서비스는 일반 서비스보다 요구가 엄격한 경우가 많아, "수집이 적다"만으로 끝나지 않을 수 있습니다.

## 1. 지금 수집·저장하는 정보 (코드 기준)

| 정보 | 어디에 | 내용 | 식별 가능성 |
| --- | --- | --- | --- |
| 기기 ID | 브라우저 `localStorage`, DB `users.device_id`, `play_records.device_id` | 앱이 처음 실행될 때 만드는 임의 UUID | 이름·연락처와 연결되지 않지만 같은 기기의 모든 기록을 묶음 |
| 보호자 설정 | DB `guardian_settings.data`(JSON), `localStorage` | 나이대(3/4/5 또는 없음), 음성·효과음 크기, 말 속도·높이, 쉬는 판 수, 조작 방식, 선택한 음성 이름 | 나이대는 아이에 대한 정보 |
| 플레이 기록 | DB `play_records` | 게임 종류, 나이대, 플레이 시간(ms), 끝까지 했는지, 시각 | 기기 ID로 묶이면 "이 기기의 아이가 언제 무엇을 얼마나 했는지"가 됨 |
| IP 주소 | nginx 접근 로그, 요청 제한 계산 | 접속한 IP | 개인정보로 볼 수 있음. 로그 보관 기간 정책 필요 |
| 외부 요청 | 브라우저 → Google Fonts | 글꼴 불러오기(`index.html`) | 접속한 IP와 브라우저 정보가 Google에 전달됨 |

수집하지 않는 것(코드에서 확인): 이름, 이메일, 전화번호, 위치, 사진·영상, 마이크·카메라, 광고 ID, 분석/추적 스크립트,
쿠키. 음성은 브라우저 내장 `speechSynthesis`로 말하기만 하고 녹음하지 않습니다.

## 2. 출시 전에 결정·확인해야 할 질문

1. **적용 법과 기준**: 어느 나라에서 출시하나요? 한국이라면 만 14세 미만 아동의 개인정보 처리 요건(법정대리인 동의 등)이
   이 앱의 "기기 ID + 나이대 + 플레이 기록"에 해당하는지, 해당하면 동의를 어떻게 받을지 확인이 필요합니다.
   해외 배포 시 미국 COPPA, 유럽 GDPR(특히 아동 관련 조항)도 해당할 수 있습니다.
2. **기기 ID가 개인정보인가**: 다른 정보와 결합해 개인을 알아볼 수 있으면 개인정보가 될 수 있습니다. 지금은 계정이 없지만
   계정 기능을 붙이면 기기 ID가 계정에 연결되어 성격이 바뀝니다. 계정 도입 설계 때 다시 점검하세요.
3. **개인정보 처리방침**: 위 1번 표를 바탕으로 쓰고, 앱 안(보호자 설정 화면 등)과 스토어 등록 정보에 링크하세요.
   수집 항목, 목적, 보관 기간, 제3자 제공/위탁(호스팅·DB), 삭제 요청 방법, 문의처가 들어가야 하는지 확인하세요.
4. **보관 기간과 삭제**: 지금은 `play_records`를 지우는 기능이 없고 보관 기간 정책도 없습니다.
   "보호자가 기기 데이터를 삭제할 수 있는 방법"과 "N개월 뒤 자동 삭제"를 정해야 합니다(할 일 후보 아래 참고).
5. **Google Fonts**: 외부로 IP가 전달됩니다. 아동 대상에서는 이를 피하려고 글꼴을 직접 호스팅(`/assets`)하는 편이
   안전하고 오프라인에도 유리합니다.
6. **로그**: nginx·백엔드 로그에 IP와 `X-Device-Id`가 남습니다. 보관 기간, 접근 권한을 정하세요.
7. **스토어 정책**: 앱 스토어(웹앱을 감싸 올리는 경우 포함)에 "어린이용/가족용" 카테고리로 올리면 광고·추적·외부 링크·
   분석 도구에 별도 규칙이 있습니다. 올릴 스토어의 최신 어린이 정책을 확인하세요.
8. **보안**: 전송은 HTTPS여야 합니다(배포 시 TLS 종단 설정). DB 비밀번호는 `.env`에만 두고, 백업 암호화·접근 권한을 정하세요.
9. **보호자 확인**: 설정 화면은 톱니 버튼을 3초 길게 눌러야 열립니다. 아이가 우연히 열기 어렵게 한 장치이지 보호자 인증이
   아닙니다. 계정이 생기면 보호자 확인 방식을 다시 설계하세요.

## 3. 코드로 줄일 수 있는 것 (할 일 후보, 아직 안 함)

- [ ] Google Fonts를 직접 호스팅해 외부 요청 없애기
- [ ] 보호자 설정에 "이 기기의 서버 데이터 삭제" 버튼(`DELETE` API: 설정, 기록, 사용자 행)
- [ ] `play_records` 자동 삭제(예: 13개월 지난 행) 배치 작업
- [ ] nginx 접근 로그에서 IP 마스킹 또는 짧은 보관
- [ ] `X-Device-Id`를 로그에 남기지 않기
- [ ] 보호자 화면에 처리방침 링크
- [ ] 계정 도입 시: 익명 기기 데이터 이전·삭제 흐름, 동의 기록 테이블

## 4. 확인할 곳 (원문)

- 개인정보 보호위원회(한국), 개인정보 보호법과 아동 개인정보 처리 안내
- 미국 FTC의 COPPA 안내, 유럽 개인정보 보호 기구의 아동 관련 가이드
- 올릴 스토어(Google Play 가족 정책, Apple 어린이 카테고리 지침) 개발자 정책
- 필요하면 개인정보 전문 변호사 또는 인증기관 상담
